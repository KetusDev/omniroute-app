# Changelog — v0.7.x (April 2026)

## v0.7.3 — Company Settings + Auth Migration
*Released: April 22, 2026*

### 🔐 Auth
- Migrated from JWT to **httpOnly cookie sessions** (`omniroute_session`)
- Added CSP (Content Security Policy) headers
- Fixed rate limit key generator for `CF-Connecting-IP`

### 🏢 Company Panel
- Redesigned company management panel
- New **8-tab settings page**: general, ranks, badges, webhooks, members, appearance, notifications, danger zone
- Company ranks, badges, webhooks, name history
- Country flags on driver profiles and community catalogs
- Heartbeat endpoint for activity status tracking
- Added `ActivityStatus`, `country`, `CompanyWebhook`, `CompanyBadge`, `CompanyNameHistory` to Prisma schema

### 🛡️ Admin
- Added `SystemRole` with admin panel
- Suspicious job review panel for admins
- Desktop heartbeat tracked server-side

### 🖥️ Desktop
- Fixed suspicious job detection logic
- Fixed token validation and API compatibility
- Company profile UI improvements
- Windows Defender false-positive mitigations
- Build script and signing env var fixes

## v0.7.2 — Discord Bot + OAuth2
*Released: April 3, 2026*

### 🤖 Discord Bot
- Added Discord bot scaffolding (`apps/bot`) with Discord.js v14
- Verification system: two-step embed panel in `#verify` channel
- All bot messages as rich Embeds
- Embed helper utility
- Fixed `dynamic import` under PM2 → replaced with `require()` (PM2 cluster mode ESM fix)
- Added `ROLE_UNVERIFIED_ID`, `CHANNEL_VERIFY_ID` env vars

### 🔗 Discord OAuth2
- Full Discord OAuth2 link flow (`/discord/link-url`, `/discord/callback`, `/discord/status`)
- JWT-signed state parameter for CSRF protection
- Discord/Steam/TruckersMP IDs **immutable** once set — locked in UI, guarded in API
- Added `discordLinkedAt` migration field
- Company Discord guard (bot only works for linked companies)
- Alternative Discord redirect env var support

### 🏗️ Infrastructure — PM2 Stack
- Removed Docker Compose, switched to **PM2** for all three services
- `ecosystem.config.cjs` with `exec_mode: fork` (required for dynamic imports)
- Updated `deploy.sh` for PM2-based deployment
- Fixed repo path `omniroute` → `omniroute-repo`
- Added `env_file` to ecosystem config for each app
- Fixed Fastify logger call signature in `discord.controller.ts`
