# Changelog — v0.9.x (June 2026)

## v0.9.0 — Telemetry Refactor + Game Map
*Released: June 2026*

### 🗺️ Game Map
- Migrated game map renderer from Leaflet to **OpenLayers** for better CRS control and tile alignment
- Fixed CRS Y-axis orientation and coordinate mapping for ETS2/ATS tile grids
- Added route drawing in layerPoint space with correct projection
- Added company logos and ETS2/ATS game map tiles
- Lazy-loaded `GameRouteMap` component to reduce initial bundle size
- Added `x`/`z` game coordinates to route points; legacy routes without coords handled gracefully
- Added game coordinate validation with unit tests
- Added i18n translations for delivery details page
- Redesigned delivery detail page with grid layout
- Centralized delivery layout and applied to map views

### 🖥️ Desktop — Telemetry Pipeline Refactor
- Refactored to **modular telemetry pipeline**: separate reader, state machine, distance integrator, delivery classifier, route recorder
- Added `completing` telemetry state for more accurate delivery detection
- Fixed `cargo_loaded` logic edge cases
- Added NSIS installer support alongside MSI
- Fixed token conflict and Windows Defender false-positive issues
- Added updater signing and local build script

### ⚙️ API
- Added job routes endpoint (`POST /jobs/:id/route`)
- Added extended delivery details with suspicion score
- Added `suspicion_score` to job responses

### 🌐 Web
- Extended delivery details page with route map overlay
- Improved company profile UI
- Stabilized Vitest setup and added page-level tests

### 🔒 Infrastructure & Security
- Enforced **Cloudflare Turnstile** on all public forms
- Added HTML sanitization on user-generated content
- Added Cloudflare ops guide and automation scripts
- Added **PostgreSQL backup scripts** and documentation
- Bound API to `localhost` only (not exposed directly)
- Added VPS hardening script
- Added `setup-cloudflared-token.sh` for Cloudflare Tunnel automation
- Documented SDK fields reference (`docs/sdk_fields.md`)
